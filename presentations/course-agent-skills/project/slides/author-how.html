Understand first

Read every file, find every assessment that uses it, follow the course’s conventions and the PrairieLearn docs.

Smallest edit

Keep the instructor’s intent and names students see. Fix alternatives as a set.

Verify

Sync, sample hundreds of variants, screenshot several, run built-in tests, grade right and wrong answers.

Tested by giving agents the fixes the diagnosis recommended, in cloned courses on a local PrairieLearn with Docker grading.
