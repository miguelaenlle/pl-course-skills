Solution

Two skills that course agents use in sequence.

1. Diagnose

Find alternatives that score or take time differently, trace each gap to the question source, recommend an edit.

diagnose-assessment-issues

2. Author

Make the edit, then verify it in PrairieLearn: variants, screenshots, question tests, grading.

author-questions

Both are plain-language skill files in github.com/miguelaenlle/pl-course-skills. Diagnosis is read-only and uses aggregate data only. Tested so far: 9 diagnosis runs across 2 courses, and 3 authoring fixes verified in PrairieLearn (two in CS 357, one in TAM 212).
