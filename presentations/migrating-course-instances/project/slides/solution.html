The agent does the mechanical work. The instructor only sees what needs judgment: conflicts, leftover dates, PrairieTest exams, per-student rules, and “anything different this term?”

migrate-course-instance · shift_dates.py scan / plan / apply / strip

The skill is a plain-language SKILL.md plus a standard-library Python script in github.com/miguelaenlle/pl-course-skills. The script inventories dates and term-specific items, maps dates, rewrites only the date strings (formatting and line endings kept), and removes UID rules and per-student overrides. If the calendar can’t be found, the agent asks for the first day of instruction but doesn’t block: it infers from the course’s own history and says so.
